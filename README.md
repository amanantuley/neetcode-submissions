## 📖 About

This repository contains my solutions to problems from **NeetCode.io**, one of the most popular platforms for mastering **Data Structures & Algorithms (DSA)** and preparing for technical interviews.

The repository is automatically synchronized using **NeetCode GitHub Sync**, ensuring every accepted solution is version-controlled and publicly available.

The goal of this repository is to:

- 📚 Strengthen problem-solving skills
- 💡 Learn multiple DSA patterns
- 🧠 Improve algorithmic thinking
- 💼 Prepare for Software Engineering interviews
- 📈 Track coding consistency and progress
